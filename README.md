# Insight
1. This repo is to learn assembly to get good at reading other's code. 
2. This repo consists of 8 projects to get this goal done.

## Projects 
- [x] Raw syscalls: hello world and an echo clone, with no libc
- [x] Reimplement libc: strlen, strcmp, memcpy, atoi, itoa
- [x] Control flow and arrays: FizzBuzz, bubble sort, binary search
- [ ] Functions and the stack: calling conventions, recursion, mixing asm with C
- [ ] Read compiler output: compile C with -O0 and -O2, then annotate the assembly by hand
- [ ] Reverse engineer small binaries: crackmes with gdb and Ghidra
- [ ] Read real-world code: disassemble coreutils and libc functions
- [ ] Capstone: a Brainf*** interpreter or ELF header parser in assembly
